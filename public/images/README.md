# Fotos ersetzen

Dateien hier **gleichen Namens** überschreiben, dann committen und pushen.

| Datei | Verwendung |
| --- | --- |
| `arena.jpg` | Startseite, volles Hero |
| `volti-platz.jpg` | Voltigieren-Karte und Seite |
| `pferd-cesar.jpg` | Mitmachen |
| `connar.jpg` | Voltigieren, Pferd |
| `jagd.jpg` | Pferdetag-Karte und Seite |
| `pferdetag-1.jpg` | Pferdetag-Galerie |
| `pferdetag-feld.jpg` | Pferdetag-Galerie |
| `richterwagen.jpg` | Pferdetag-Galerie |
| `maibaum.jpg` | Feste / Maifeier |
| `geschichte-1.jpg` | Vereinsseite |
| `urkunde.jpg` | Vereinsseite |

Querformat (ca. 1600–2400 px breit) für Hero und Karten, Hochformat für Porträts. JPEG, unter 500 KB wenn möglich.

Pfade und Bildtexte stehen in `src/data/site.ts` unter `photos`.
